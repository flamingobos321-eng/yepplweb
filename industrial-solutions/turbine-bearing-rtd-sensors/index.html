RTD Sensors for Turbine Bearings

Turbine bearing RTD sensors are selected around the bearing location, mechanical fit and monitoring-system interface. A clear point description is more useful than a generic turbine specification.

Define the bearing point and how the sensor contacts or sits at that location. Provide available space, mounting, lead route, vibration context, expected conditions, access and instrument input. If several bearings are involved, identify each position so the required geometry and cable arrangement can be reviewed separately.

The catalogue includes Ring Type RTD, Ring Type RTD with L Bend and Ring Type RTD with SS Conduit. The existing motor, generator and bearing application guidance names ring-type RTDs, L-bend ring RTDs and conduit RTDs as forms to review for mechanical fit. These options should not be treated as interchangeable.

Confirm element requirement, ring or bend geometry, conduit or lead construction, dimensions, mounting and monitoring input from the product records. Do not infer bearing size, materials, temperature limits or installation requirements. Equipment drawings and the intended monitoring channel are important selection inputs.

Share the bearing drawing, available clearance, lead route and instrument details with Yog Electro Process. This allows a focused discussion of the listed RTD forms for the turbine-bearing measurement point.

Bearing RTD enquiries should include the bearing drawing or a clear description of the available ring position, bend direction and lead route. Ask whether an SS conduit is required by the installation arrangement, what element input the monitor accepts and how the sensor will be replaced. Identify each bearing location separately. These details allow Ring Type RTD, Ring Type RTD with L Bend and Ring Type RTD with SS Conduit to be reviewed for mechanical fit.

Include the bearing drawing, monitor input and cable route in the enquiry. Identify whether the point calls for a ring, L-bend or conduit arrangement and provide the available space. This gives the product discussion a clear mechanical context without assuming an unlisted bearing construction.

State the desired reading unit, channel arrangement and connector standard where known. Clarify whether each bearing assembly remains installed or is changed during maintenance. This helps keep the selected option aligned with the monitoring method, wiring and maintenance routine.

Include the project point list, drawing references and instrument details so the buyer and engineering team discuss the same measurement arrangement.
